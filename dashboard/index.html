01 / ABOUT RFGN

Intelligence Beyond Connections

RFGN — Reinforced Federated Graph Network is an intelligent fraud detection architecture combining Graph Neural Networks, Federated Learning and Reinforcement Learning to analyze financial transaction relationships across decentralized networks.

02 / TECHNOLOGY

Three Intelligence Layers

01 / GRAPH AI

GRAPHSAGE

GraphSAGE processes transaction relationships and node features to produce fraud probabilities from graph-structured financial data.

02 / FEDERATED AI

FEDERATED LEARNING

Multiple clients participate in decentralized training while the global model is produced through federated aggregation.

03 / REINFORCEMENT AI

DQN

The DQN decision layer selects the fraud detection threshold used by the deployed inference pipeline.
